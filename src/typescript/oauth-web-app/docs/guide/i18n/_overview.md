## 🌐 Supported Languages

- 🇬🇧 English (en)
- 🇨🇳 Simplified Chinese (zh-CN)
- 🇹🇼 Traditional Chinese (zh-TW)
- 🇸🇦 Arabic (ar)

## 🔧 Technology Stack

- **Framework:** React 19 + Next.js 15 (App Router)
- **i18n Library:** i18next + react-i18next
- **Loader:** JSON files under `public/locales/` (static loader)
