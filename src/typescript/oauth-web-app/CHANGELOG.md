## How to Report Bugs

Found a bug? [Create an Issue](../../issues/new?labels=bug) with:

1. **Bug Description** - Clear description of the issue
2. **Reproduction Steps** - Step-by-step instructions
3. **Expected Behavior** - What should happen
4. **Actual Behavior** - What actually happened
5. **Environment Information**:
   - OS (Windows/Mac/Linux)
   - Node.js version
   - npm version
   - Browser (if applicable)

---

## How to Request Features

Have a feature idea? [Create an Issue](../../issues/new?labels=enhancement) with:

1. **Feature Description** - Clear feature description
2. **Use Case** - Why you need this feature
3. **Expected Solution** - How you'd like it implemented
4. **Alternative Solutions** - Other possible approaches

## Release Process

1. **Development & Testing** - Develop and test on feature branch
2. **Version Update** - Update version number per semantic versioning
3. **Changelog Update** - Record all changes
4. **Release Creation** - Create Release on GitHub
5. **Notify Users** - Send release notification
