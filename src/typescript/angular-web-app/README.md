# 🎯 Sync Core AI - Angular OAuth Demo Application

Enterprise-grade Angular OAuth authentication and multi-language demo application, showcasing modern web development best practices.

---

## ✨ Core Features

- **🔐 OAuth Authentication System** - Support Google, GitHub, Microsoft
- **🌍 Multi-language Support** - 4 languages (English, Simplified Chinese, Traditional Chinese, Arabic)
- **🎨 Modern UI** - Angular 19 standalone components with responsive design
- **📚 Complete Documentation** - 10,000+ lines of industry-standard documentation
- **🧪 High Quality Code** - 80%+ test coverage with automated testing
- **✅ Professional Standards** - GitHub Actions CI/CD, code review process, automated quality checks

---

## 🚀 Quick Start

### Prerequisites

```
Node.js >= 18.0.0
npm >= 9.0.0
Angular CLI >= 19.0.0
```

### Installation and Run

```bash
# 1. Clone repository
git clone <repository-url>
cd angular-web-app-template

# 2. Install dependencies
npm install

# 3. Start development server
npm start
```

Application will open at `http://localhost:4200/`

## 🎓 Core Features Demo

### 1️⃣ OAuth Authentication

Support three major OAuth providers with mock integration for demo purposes:

- **🔵 Google OAuth** - Fast, secure authentication
- **⚫ GitHub OAuth** - Developer-friendly
- **🔶 Microsoft OAuth** - Enterprise solution

**Documentation**: [OAuth Implementation Guide](./docs/guide/oauth/implementation.md)

### 2️⃣ Multi-language Support (i18n)

Complete internationalization system supporting 4 languages:

- 🇬🇧 **English** - Complete translation
- 🇨🇳 **Simplified Chinese** - Complete translation
- 🇹🇼 **Traditional Chinese** - Complete translation
- 🇸🇦 **العربية** - Complete RTL support

Dynamic language switching without page reload.

**Documentation**: [i18n Complete Guide](./docs/guide/i18n/implementation.md)

### 3️⃣ User Registration

Complete user registration process with:

- Email validation
- Password strength checking
- Service terms agreement
- Real-time form validation

**Documentation**: [Complete Implementation Guide](./docs/getting-started/installation.md)

### 4️⃣ Protected Dashboard

Secure user dashboard accessible only after authentication with:

- User profile information
- OAuth provider display
- User avatar
- Logout functionality
