## 💡 Documentation Organization Principles

### Three-Tier Structure

```
1️⃣ Getting Started (Beginner Level)
├─ Quick start
└─ Installation and configuration

2️⃣ Guides (Intermediate Level)
├─ i18n (Internationalization)
├─ OAuth (Authentication)
├─ Development guide
└─ Deployment guide

3️⃣ Reference (Advanced Level)
├─ API Reference
├─ Architecture Design
├─ Process Management
└─ Troubleshooting
```

### Each Section Has an Overview File

Every major section has an `_overview.md` file that explains the section's content and provides quick navigation:

```
docs/guide/i18n/_overview.md          # i18n section navigation
docs/guide/oauth/_overview.md         # OAuth section navigation
docs/process/_overview.md             # Process management navigation
```
